# DJ Bombchelle inbox

Drop files here and the scheduled task will use them.

- `audio/<album-slug>.mp3` (or .wav / .m4a): a 15–60 second clip, or the full track, for an album. With a clip here, that album gets a reel with sound instead of a silent one. Name it after the album, e.g. `audio/built-in-boston.mp3`. To start the clip somewhere other than the beginning, add a line to `audio/starts.txt` like `built-in-boston 42` (seconds).
- `photos/` and `clips/`: photos or short videos of you in the studio, at the decks, or at events. These are used for occasional behind-the-scenes posts.
