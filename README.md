# social-media-assets

Public media for ApexLit Publishing Group and PuzzleVybe social posts. Buffer pulls each scheduled post's image or video from the links in this repo, so files must stay here until their post is published.

- `apexlit/<date>/`, `puzzlevybe/<date>/`: images and videos for each batch
- `tools/`: the templates that render posts, plus a history of what was posted and when

Maintained by Claude scheduled tasks.
